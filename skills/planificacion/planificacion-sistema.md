# Planificación del sistema

No elegir framework o cloud por costumbre. Primero definir problema, usuarios, outcomes, restricciones de costo/operación/compliance y NFR. Las decisiones tecnológicas deben justificarse contra esas restricciones y registrarse en manifiesto/ADR.
